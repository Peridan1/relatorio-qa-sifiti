### 🎥 Ferramenta Recomendada para Gravação de Vídeos
* **Extensão Jam (Chrome Web Store)**:  
  [Instalar Extensão Jam](https://chromewebstore.google.com/detail/jam/iohjgamcilhbgmhbnllfolmkmmekfmci?hl=pt-BR&pli=1)
  * A extensão Jam captura vídeo da aba, áudio, logs de console e requisições de rede automaticamente.
  * Cole os links gerados pelo Jam ou envie os arquivos `.webm` / `.mp4` para a pasta do Google Drive do projeto.
